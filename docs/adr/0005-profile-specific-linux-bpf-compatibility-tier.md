# Add a Profile-Specific Linux BPF Compatibility Tier

Keep the existing fixed-layout BPF v1 contract stable and add a separately versioned, narrowly scoped Linux BPF compatibility tier for the unmodified, pinned libbpf-bootstrap C `profile` example. The tier will implement only capabilities proven necessary by its reproducible BPF ELF, including required object BTF/map metadata handling, Ring Buffer reserve/submit, kernel and user stack capture, and software CPU-clock frequency sampling; hardware PMU support remains out of scope, and CO-RE is considered only if the inspected artifact actually contains CO-RE relocations. The audited upstream commit is a dependency snapshot, not the final version pin; lock the supported commit and derive the precise ABI from its generated artifact before implementation.
